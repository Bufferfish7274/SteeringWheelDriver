# GM6020

## 目标

把 GM6020 的原始反馈转换为舵轮本地角，并完成：

```text
目标角 -> 位置 PID -> 目标 RPM -> 速度 PID -> 电压 raw
```

当前电机使用旧版固件默认电压控制，不是电流控制。

## CAN 协议

### 反馈

- 标准数据帧；
- ID：`0x204 + motor_id`；
- DLC：8；
- 周期约 1 kHz；
- `Data[0..1]`：机械角；
- `Data[2..3]`：转速；
- `Data[4..5]`：转矩电流 raw；
- `Data[6]`：温度。

### 电压控制

| 电机 ID | 控制 ID |
|---|---|
| 1～4 | `0x1FF` |
| 5～7 | `0x2FF` |

每帧包含四个电机槽位，每个槽位为大端 `int16` 电压 raw。当前电压限制为
`20000`，绝对硬件范围为 `25000`。

## 角度换算

```text
delta_raw = (raw_angle - zero_raw) mod 8192
motor_deg = delta_raw * 360 / 8192 * angle_sign
angle_deg = wrap360(motor_deg / gear_ratio)
```

`zero_raw` 是机械零位的原始角。修改零位会同时改变反馈坐标和目标坐标。

当前方案为直驱，`gear_ratio=1.0`。若使用减速器，仅靠单圈电机角不能确定
舵轮多圈绝对位置，需要外部绝对编码器或多圈解绕。

## 方向

- `angle_sign`：编码器原始递增方向与舵轮本地正方向的关系；
- `voltage_sign`：正电压命令是否让舵轮朝本地正方向运动；
- 两个符号应在装配后分别验证，不能用其中一个掩盖另一个的错误。

## 控制行为

`Gm6020::init()` 接收一次完整的 `Gm6020::Config`，其中包含设备身份、
机械安装方向、两级 PID、控制周期、运行限幅和在线超时。驱动不定义产品
默认 PID，也不会在初始化后再次注入或重建调参。

1. 位置误差先经过 `wrap180`，确保 359° 到 1° 只走 2°；
2. 位置 PID 输出目标 RPM，并限制到 `max_speed_rpm`；
3. 速度 PID 输出电压 raw；
4. 应用 `voltage_sign` 和 `voltage_limit_raw`；
5. 每 1 ms 发送一次控制帧。

驱动提供位置、速度和直接电压三种 `Gm6020::ControlMode`。位置模式执行
位置 PID 到速度 PID 的串级控制；速度模式直接把目标 RPM 送入速度 PID；
电压模式绕过两个 PID，经过电压限幅后直接发送 raw 电压。

`Gm6020::setControlMode()` 发生有效变化时会先失能、发送零电压、清目标并
复位 PID。`Gm6020::enable()` 会把目标重置到当前角并清 PID；
`Gm6020::disable()`
会发送零电压。反馈超过配置的 `online_timeout_ms` 未更新时，驱动自动
进入离线并输出 0。

## 发送诊断

`Gm6020` 保存最近发送状态、电压、标准帧 ID、8 字节负载及成功/忙/错误计数。
这些字段只表示 HAL 发送邮箱结果，不直接代表电机实际产生转矩。
