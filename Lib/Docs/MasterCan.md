# MasterCan

## 目标

解码主控控制帧和心跳帧，并向应用提供：

- 最后收到的 ERPM 和角度目标；
- 是否已经收到控制目标；
- 主控链路是否仍有效；
- 控制帧和心跳帧时间戳。

## 协议

### 控制帧

- 标准数据帧，ID `0x100 + group`；
- DLC 8；
- 每组包含两个舵轮，组号 `group = (wheel_id + 1) / 2`；
- `Data[0..1]`：1/3 号舵轮的大端 `int16 ERPM`；
- `Data[2..3]`：1/3 号舵轮的大端角度码；
- `Data[4..5]`：2/4 号舵轮的大端 `int16 ERPM`；
- `Data[6..7]`：2/4 号舵轮的大端角度码。

| 舵轮 | 控制 ID | 帧内槽位 |
|---:|---:|---|
| 1 | `0x101` | `Data[0..3]` |
| 2 | `0x101` | `Data[4..7]` |
| 3 | `0x102` | `Data[0..3]` |
| 4 | `0x102` | `Data[4..7]` |

ERPM 使用完整 `int16` 范围 `-32768..32767`，接收端不额外限幅。
角度码合法范围仍为 `0..16383`。

角度换算：

```text
target_angle_deg = angle_code * 360 / 16384
```

越界角度码会被夹紧到最后合法值。

### 心跳帧

- 标准数据帧，ID `0x110 + group`；
- DLC 8；
- 1/2 号舵轮使用 `0x111`，3/4 号舵轮使用 `0x112`；
- 负载不参与控制。

## 持久命令语义

主控在组内任一轮目标变化时发送该组控制帧，帧内应同时包含两个轮的当前
目标。因此目标不能因为“控制帧变旧”而失效。

```text
control_seen = 当前有效链路周期内是否收到过控制目标
link_valid   = 控制帧或心跳是否仍在配置的超时窗口内
```

应用最终使用：

```c
if (master.link_valid && master.control_seen) {
    /* 可以执行 drive_erpm 和 target_angle_deg */
}
```

## 超时与恢复

- 控制帧同时刷新控制时间戳和心跳时间戳；
- 任一有效的本组控制帧都会刷新本轮的 `control_seen`，即使本轮的槽位值
  没有变化；
- 心跳处理前先按旧时间戳执行一次更新，以检测是否已经断链；
- 链路失效时清除 `control_seen`，但保留最后 ERPM 和目标角用于诊断；
- 心跳恢复只恢复 `link_valid`，旧目标不会自动复活；
- 必须收到新的控制帧，才能重新置位 `control_seen`。

所有时间差使用 `uint32_t` 无符号减法，因此支持毫秒时间戳自然回绕。

## 边界

- 只接受标准数据帧；
- 只接受 DLC 8；
- 错误轮号、扩展帧和远程帧会被忽略；
- 轮号和链路超时由 `MasterCan::Config` 在初始化时注入；
- 轮号决定组 ID 和组内槽位，错误的组 ID 会被忽略；
- 模块不配置 CAN 过滤器，也不启动 CAN。
